S2TP Automatic Speech Recognition (ASR)

This project explores Automatic Speech Recognition (ASR) technology with a personal focus on its potential impact for the deaf community. I utilized the LibriSpeech dataset, which contains over 1,000 hours of English speech, to develop a Connectionist Temporal Classification (CTC)-based model. The model was trained to transcribe audio into text by predicting character sequences, addressing challenges like variable speech rates and background noise. I also conducted a comparative analysis with Meta's Wav2Vec model, a state-of-the-art self-supervised learning approach, to benchmark performance. Despite encountering issues with model convergence and accuracy (achieving a word error rate of approximately 25%), this project provided deep insights into the complexities of ASR systems, including the need for robust preprocessing, large-scale data, and computational resources. Future improvements could involve fine-tuning with domain-specific data or exploring hybrid architectures.

NFL 2019 Big Data Bowl Multi Model Analysis

This project was developed off of the NFL Big Data Bowl, a Kaggle competition leveraging NFL Next Gen Stats. Using data from the 2019 competition (covering games from 2017–2019), the goal was to predict play outcomes—specifically, the number of yards gained or lost—based solely on pre-snap features. The prediction task was framed as a regression problem with a target range of -100 to 100 yards. The dataset was split into training (80%), validation (10%), and test (10%) sets. Neural network models were trained using PyTorch with batched data loaders and controlled random seeds for reproducibility. Models utilizing tree methods as well as SVM have been implimented as well.

UFC EDA and Winner Prediction

In this project, I explored the dynamics of UFC fights using detailed bout-level data to uncover patterns and predict match outcomes. I engineered a rich set of features—including fighter performance stats, physical attributes, and betting odds—and applied logistic regression to classify winners. I also used PCA for dimensionality reduction and insightful visualizations. Key highlights: Cleaned and transformed complex sports data from Kaggle’s Ultimate UFC Dataset Built predictive models using logistic regression and validated them with cross-validation Analyzed fight trends and performance metrics across weight classes and genders Visualized decision boundaries and key fighter statistics with Seaborn and Matplotlib Delivered actionable insights for betting and sports analysis audiences This project demonstrates my ability to work with real-world sports data, engineer meaningful features, and build interpretable models—all while communicating findings through data storytelling.
